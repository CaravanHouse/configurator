# Конфигуратор проекта для сайта CaravanHouse

[![CI](https://github.com/CaravanHouse/configurator/actions/workflows/ci.yml/badge.svg)](https://github.com/CaravanHouse/configurator/actions/workflows/ci.yml)

Клиент отмечает, что ему нужно (бот, сайт, мини-апп и функции), и сразу видит примерную смету и срок. Заявка прилетает вам в Telegram с кнопками статуса.

**Что показывает клиенту:** сайт + бот в связке. Это ещё и рабочий инструмент: он собирает заявки.

## Важно: цены
Все цены и сроки в `shared/pricing.ts` — **примерные заглушки**. Поправьте числа под ваш прайс: сайт и сервер считают смету из этого одного файла.

## Что внутри
- Смета пересчитывается сразу: скидка 10% за комплекс, наценка за срочность, диапазон «от и до»
- Сумму считает сервер заново, цифрам из браузера не верит
- Защита от спама: скрытое поле-ловушка и лимит 5 заявок в час с одного IP
- Заявка приходит в Telegram: кнопки «Взять в работу / Отклонить / Готово», видно, кто взял
- `/leads` показывает открытые заявки, `/id` помогает узнать id чата для `ADMIN_CHAT_ID`

## Запуск
```bash
npm install
cp .env.example .env     # BOT_TOKEN и ADMIN_CHAT_ID
npm run build
npm start
```
Без токена сервер работает, заявки сохраняются в `data/leads.json`. Тесты: `npm test`.

## Данные
Заявки хранятся в JSON-файлах в папке `DATA_DIR` (по умолчанию `./data`). Диск Railway очищается при каждом деплое, поэтому подключите к сервису Volume с путём `/data` и задайте `DATA_DIR=/data`, тогда данные переживут перезапуски и деплои. При большой нагрузке переходите на PostgreSQL.
